# Expense Tracker – JavaFX Mini Project

## Description
This is a Simple Expense Tracker application developed using JavaFX and SQLite database.  
The application allows users to add, view, and delete daily expenses.

## Technologies Used
- Java
- JavaFX
- SQLite
- JDBC
- VS Code

## Features
- Add Expense
- View Expenses
- Delete Expense
- SQLite Database Storage
- JavaFX UI Screens

## Project Structure
src/
 - App.java
 - DBConnection.java
 - Expense.java
 - AddExpenseController.java
 - ViewExpenseController.java

resources/
 - addExpense.fxml
 - viewExpense.fxml

expense.db

## CRUD Operations
- **Insert** – Add Expense
- **Read** – View Expense
- **Delete** – Remove Expense

## How to Run
1. Install JDK 17 or higher (used 21)
2. Install JavaFX SDK
3. Configure VM options
4. Run App.java

## Learning Outcome
- JavaFX UI development
- Database connectivity using JDBC
- CRUD operations
- Scene navigation
